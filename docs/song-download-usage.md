# 下载歌曲、歌词与管理文件

在歌曲行右侧点击下载图标，或使用播放栏的“下载当前歌曲”。歌单、专辑顶部右侧的下载按钮与播放、收藏按钮同组，可下载全部歌曲；歌单会先读取完整曲目清单。普通列表可进入“选择歌曲”，勾选后下载；搜索结果的全选仅包含已经加载的歌曲。

下载时选择电脑上的目录或已经挂载的 TF 卡、U 盘目录。默认建议系统音乐目录下的 `NetEase Downloads`。保存位置和选项会作为后续默认值，也可以在首选项的“下载默认设置”中修改。

## 音频与歌词

输出是真正的 MP3：128、192 或 320 kbps，固定码率、44.1 kHz、双声道，默认 192 kbps。歌曲带 ID3v2.3 歌名、歌手、专辑标签；开启编号时写入曲序。已有符合输出约束的 MP3 保留音频帧，其余源音频通过 GStreamer 转换。输出码率不会提升较低质量源音频的音质，任务详情显示源格式和码率。

可以选择音频与歌词、仅音频或仅歌词。歌词支持同时导出 LRC、TXT、SRT，以及原文、独立译文或双语。默认原文 LRC、UTF-8；老设备可以尝试 GBK。GBK 无法表示的字符会导致该歌词文件导出失败，可以点击“按 UTF-8 重试”。UTF-8 重试会保留已成功的 GBK 文件，各文件分别记录编码；以后要求整套 UTF-8 输出时会生成新副本。没有时间轴时只能导出 TXT，没有译文时保留原文并显示相应结果。

歌曲和歌词使用同一基础文件名。可为歌单创建子目录、添加顺序编号；子目录附加歌单 ID，便于区分同名歌单。独立译文使用 `.translated.lrc` 等后缀。

## 下载管理

打开主菜单的“下载与文件管理”。“下载任务”显示阶段、进度、目录及各文件的结果，支持取消和手动重试。取消会保留已经完成的文件；重试保留成功结果，只处理缺失或失败的输出。关闭页面后队列继续，退出软件会停止任务；重启后需手动重试。正常退出会在后台等待工作线程停止，最长 20 秒；遗留的本应用临时音频会在下次启动清理。

同时最多处理两首歌曲、一个音频转换。下载与播放使用独立管线。试听片段、空链接、传输截断和时长不符的音频不会标为完整下载。能否获取整首歌曲取决于当前登录账号和服务返回的资源。

提交后，底部提示分别显示新加入队列、已保存并跳过、已在队列及无法获取的歌曲数量。重复下载同一目录中已保存且未变动的相同输出时，会显示“已保存，跳过重复下载”，而不是把它算成新加入队列。仅补齐缺失歌词等输出仍算作新任务。

不会覆盖已有文件：未纳入管理的同名文件保留，新文件会增加区分后缀；已保存且未变动的相同输出会跳过。正式文件与播放缓存分别管理，清除下载历史只清除任务记录。

## 已保存文件与删除

在“已保存文件”中按目录筛选、搜索和选择文件。“刷新文件状态”会核对文件是否存在及是否被外部修改；“扫描目录”可预览并纳入该目录中的已有 MP3 和同名 LRC、TXT、SRT、独立译文。扫描不跟随符号链接，已有文件不会按歌名猜测网易歌曲 ID。

“删除所选文件”先选择音频、歌词或两者，再显示目录、具体文件路径和处理字节数。可以移到系统回收站或显式永久删除；回收站失败会保留文件，永久删除需要重新确认。移到同一设备的回收站可能不会释放其可用空间。只删除所选位置的文件，其他目录的副本和网易云歌单不受影响。

文件被替换、目录发生变化或任务正在写入时会拒绝删除。删除时先隔离文件并再次校验，防止确认后文件被替换；无法还原时会报告保留文件所在的位置。回收站使用 [Freedesktop Trash 格式](https://specifications.freedesktop.org/trash/latest/)，记录原路径以便桌面恢复；文件系统不支持安全回收站时会保留原文件。外部删除文件后可使用“移除缺失记录”；这只更新索引。

TF 卡断开后，该保存位置会失效，排队任务停止，不会重建旧挂载路径。重新挂载后选择原目录并重试；重启后可移除设备也需要确认。无法确认原设备身份时，先扫描并纳入实际目录，再重新下载。临时文件只按本应用记录的归属清理。

## 从源码构建

使用仓库已有 Meson 安装流程；安装会更新资源、翻译和 GSettings schema。只替换可执行文件而不更新资源会缺少新界面或设置。保留本机所需的 Libadwaita `v1_5` 特性。

下载转换需要 GStreamer 的 `lamemp3enc`、`mpegaudioparse`、解码、音频转换及重采样插件；通常由 plugins-base、good、ugly，以及相应解码插件包提供。缺少插件时任务显示原因，仅下载歌词仍可使用。本功能还使用 GStreamer pbutils 探测完整媒体。

自动测试可运行 `cargo test --offline -j 1`。界面测试需要可用显示服务；网络样本仅由临时本地服务提供，不需要网易账号。`-j 1` 避免多个 GTK 测试程序同时链接造成内存不足。

## 下载失败后重试

若批次提示“完成 0 / 2”，打开主菜单的“下载与文件管理”，在“下载任务”查看每首歌的具体错误并点击“重试”。2026-10-05 修复了歌曲详情请求参数的多余转义，旧版本会在写入文件前报“Cannot verify the song duration”；重新编译、安装并退出重开后即可重试原任务。

可选的线上回归测试需显式运行 `tests/download_api.rs` 中的忽略测试，并通过环境变量 `NCM_READONLY_COOKIE_FILE` 提供现有登录凭据文件路径。该测试只读登录文件，下载到自动清理的临时目录，检查两首复现歌曲的完整 MP3；默认测试不联网访问音乐服务、不读取登录文件。
